Amber lines = each agent's strongest complementary-fit binding (the actual attention the transformer computes; brighter = stronger). Interaction is load-bearing — with no neighbours an agent cannot move. Aliveness is measured, never optimized.
One weight-tied transformer block, iterated — each application is one frame. Strict transformer-only: every operation is attention / MLP / LayerNorm.

There is no trained loss and no gradient descent — this is a fixed-rule dynamical system (the weights Wᵥ, MLP, J, M are fixed). What the local forces effectively descend is a packing / binding energy — ↓ steric clash ⟨Cᵢ,Cⱼ⟩, ↑ complementary fit ⟨Cᵢ,M·Cⱼ⟩ — plus a non-gradient skew term (zJ) that keeps it off-equilibrium so it never settles. The aliveness readout above is a one-way measurement; it never feeds back into the update (measure-don't-reward).
