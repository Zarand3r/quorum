softmax = the Boltzmann distribution (temperature dial)
Attention is statistical mechanics. The softmax weight A_ij = exp(scoreᵢⱼ/τ) / Σₖ exp(scoreᵢₖ/τ) is exactly the Boltzmann / Gibbs distribution p_j ∝ e^(−E_j / kT) with the binding score as negative energy (E = −score), the softmax denominator as the partition function Z, and the temperature τ as kT. So each agent's attention is the thermal occupation of its neighbour "states". The temperature slider is a real thermodynamic temperature:
  • low τ → sharp (→ argmax): each agent commits to its single best bond → discrete lock-and-key pairing, ordered/crystalline, resists collapse but can freeze.
  • high τ → flat (→ uniform): attention averages over all neighbours → mean-field consensus → homogenization / collapse (the rank-collapse the block fights).
This is the same identity that makes modern Hopfield networks (attention = one energy-descent step) exact.
objective & physical law — living = inference = optimization
No separate train / infer / run phases: each tick IS one transformer forward pass, so running the sim is the computation is the optimization — no separation. The physical law is baked into the grounded attention: the dock score ⟨Cᵢ, M·Cⱼ⟩ is a real binding energy (by Parseval, attention = contour overlap). The dynamics descend a packing/binding free energy Φ (↓ steric clash ⟨Cᵢ,Cⱼ⟩, ↑ complementary fit ⟨Cᵢ,M·Cⱼ⟩) driven off-equilibrium by a non-gradient skew flux zJ so it never settles — ẋ = −D∇Φ + J, the potential-flux form of a living, dissipative system. So there IS a thermodynamic objective (Φ); the inference relaxing it is the living.

State vs weights: by default the network weights are fixed (the physics /laws) and only the state (the embeddings / the fold) is optimized. Aliveness above is measured, never fed back (measure-don't-reward).
plasticity — weights that learn while alive (Hebbian, NO backprop)
Turn up the plasticity slider and a plastic memory W_fast (the heatmap under the dish) learns while the sim runs — you watch ‖W‖ grow from 0. How it learns: a local Hebbian outer-product write W_fast ← γ·W_fast + η·(kᵀv) — no loss, no gradient, no backprop — which is exactly the fast-weight form of linear attention (Schlag+2021; Schmidhuber 1992). The decay γ is a gated-linear-attention forget gate (homeostasis). It's read as z·W_fast into the message, so the interaction adapts with the history of activity. Only the fast weights learn; the slow physics weights stay fixed → plasticity changes couplings, not laws (faithful to synaptic plasticity, not evolution). It is load-bearing: freezing the learning removes its aliveness gain.
