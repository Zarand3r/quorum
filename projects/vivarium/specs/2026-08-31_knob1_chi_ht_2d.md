# Knob 1: remove chi_HT, tested in 2-D

**Why this knob, and why 2-D.** `chi_HT = -0.25` is the one term hand-set purely to manufacture
amphiphilicity: `field.py` records that at the +0.20 default "a head is indifferent between a head
neighbour and a tail neighbour... the ordered bilayer is not even a local minimum". Removing it and
letting head SIZE do that work is the cleanest single chemistry-to-geometry substitution.

2-D because that is the only place this project HAS a working vesicle (2/18 fresh seeds), so it is the
only place a knob removal can be checked against a known-good baseline. Every previous knob-reduction
run this session was 3-D, against a target never achieved — which is why none of them was
interpretable.

Removing it halves rather than eliminates amphiphilicity: effective head-tail goes **-0.500 -> -0.250**,
because `chi_HW = 0.75` vs `chi_TW = 0.00` carries the other half.

## Screen — 200k steps, 3 seeds/arm, N=160, L=65, kT=0.45, phi=0.55

    baseline chi_HT = -0.25   largest_max  43, 78, 46   mean 55.7
    removed  chi_HT =  0.00   largest_max  63, 28, 33   mean 41.3

    ranges overlap: True
    within-arm spread (baseline) 35  >  between-arm gap of means 14.3
    vesicle calls: 0 in BOTH arms.  n_enclosed >= 1 at 0 checkpoints in both arms.

## Verdict: NOT DECIDABLE, by design

**No gross failure.** Removing the knob did not collapse aggregation; both arms build aggregates of
28-78 lipids and the arms overlap completely. The baseline's own seed-to-seed spread (35) is larger
than the difference between arms (14.3), so this design can only detect a large effect.

**But the endpoint was unreachable.** 0 vesicles in the BASELINE arm — the configuration that
historically gives 2/18 — because 200k steps does not reach the regime where closure happens in this
system (formation takes 6e5-1e6 steps). Neither arm could pass or fail the test that matters.

So this screen rules out only the strongest failure mode: chi_HT is not load-bearing for basic
aggregation on this timescale, consistent with the arithmetic that the water terms carry half the
amphiphilicity. It says **nothing** about whether the 2/18 vesicle rate survives.

## Next, and it is expensive

The real test is a long 2-D run: 10^6 steps, enough seeds to compare against 2-in-18. At the measured
~6 ms/step for this system that is ~1.7 h per seed; 18 seeds per arm is ~10 h at 6-way parallelism, and
detecting a change from a 2/18 base rate needs roughly that many.

Cheaper intermediate worth doing first: re-run the SAME screen at 10^6 steps with 6 seeds/arm and ask
only whether the baseline reproduces any vesicles at all. If the baseline gives 0/6 at 10^6 steps, the
comparison is unaffordable at this rate and the endpoint has to change (e.g. score the closure
precursor — arc formation and end-gap — rather than closure itself).
